# Curso de git & GitHub
Este curso tiene como objetivo enseñar los conceptos básicos de Git y GitHub, herramientas esenciales para el control de versiones y la colaboración en proyectos de desarrollo de software. A lo largo del curso, aprenderás a crear repositorios, realizar commits, gestionar ramas y colaborar con otros desarrolladores utilizando GitHub.

1. Introducción a Git y GitHub

   - ¿Qué es GitHub?

   - Configuración inicial
